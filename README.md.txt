# Simple AI Chatbot

This is a simple Python chatbot project. It takes user input and gives responses using basic logic and conditions.

## Features

- Takes user input
- Responds to simple questions
- Explains Python, AI, LLM, and GitHub
- Uses if, elif, and else conditions
- Runs in the terminal
- Beginner-friendly Python project

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Run the Python file using:

python chatbot.py

4. Type your question in the terminal.
5. Type `bye` to exit the chatbot.

## Example

You: hello  
Bot: Hello! How can I help you?

You: what is python  
Bot: Python is a popular programming language used for web development, AI, data science, and automation.

You: bye  
Bot: Goodbye! Have a great day.
